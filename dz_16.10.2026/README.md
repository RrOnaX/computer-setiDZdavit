Конспект !
DNS — это автоматическая распределенная система серверов, которая переводит понятные человеку буквенные имена сайтов в числовые IP-адреса для работы браузеров. До ее создания в сети ARPANET данные заносились вручную по звонку в сетевой центр, но ручной ввод стал невозможен из-за лавинообразного роста интернета.
При поиске IP-адреса компьютер сначала проверяет локальный файл hosts. Если совпадений нет, запрос отправляется локальному серверу интернет-провайдера, который опрашивает региональные узлы и находит нужный IP-адрес. Полученный адрес локальный сервер сохраняет в память для кэширования, что значительно ускоряет повторные запросы пользователей. Если сайт меняет свой IP-адрес, кэш на всех серверах полностью обновляется в течение суток.
Вся глобальная инфраструктура держится на 13 главных корневых серверах, которые за счет полных копий по всему миру расширены до 123 рабочих узлов. В России развернуто 5 таких копий, физически расположенных в Москве, Санкт-Петербурге, Ростове-на-Дону, Новосибирске и Екатеринбурге. Помимо крупных провайдерских узлов существуют персональные DNS-серверы для настройки на телефонах с целью блокировки рекламы. Сам протокол прикладного уровня модели OSI встроен во все операционные системы по умолчанию, а расширение DNSSEC надежно защищает пользователей от хакерских атак с подменой IP-адресов.
Архитектурно система обладает распределенным администрированием разными организациями, распределенным хранением информации по своим зонам, древовидной иерархической структурой и физическим резервированием данных. Вся информация о доменах хранится в DNS-зоне, содержащей записи типов A для IP-адреса сайта, MX для почты, CNAME для поддоменов, NS для адресов серверов ресурсов, TXT для текстовых данных и SPF для списков отправки. Главной обязательной записью является SOA (Start Of Authority), которая обеспечивает обмен данными в кластерах и содержит параметры Primary Name Server, Hostmaster, Serial number, Refresh, Retry, Expire и Minimum TTL.
Доменное имя строится иерархически справа налево и начинается со скрытого нулевого корневого уровня в виде точки. Далее идет первый уровень доменной зоны, разделенный на национальные домены стран и общие тематические пространства. При этом в зонах США, ЕС, Эстонии, Украины, Азербайджана и Ирландии регистрировать сайты могут строго только местные резиденты. На втором уровне находится уникальное основное имя сайта от создателя, регистрируемое через аккредитованные ICANN компании. Третий уровень представляет собой поддомен для логического разделения ресурса на независимые языковые версии или филиалы, а последующие уровни из-за сложности набора почти не используются
